# Original-image calibrated photometry, 9 October 2026

The corrected pipeline has now run on verified current MAST bytes for the
GOODS-S obs026 F444W/F090W/F200W images. This closes the baseline's specific
"no actual image rerun" gap for this field, not for the complete historical
26-product archive. The products were reprocessed with CAL_VER 3.0.0; these
are not byte-identical reproductions of the old processing. These individual
exposure `i2d` products cover full image arrays but are not deep observation-level
mosaics. Historical catalogs and reports remain unchanged.

| Stage | Number |
| --- | ---: |
| F444W segmentation detections / measured proposals | 1,134 |
| Both F090W and F200W aperture coverage >=90% | 246 |
| Fully testable calibrated three-band measurements | 243 |
| Untestable proposals | 891 |
| Testable proposals failing the configured dropout cut | 236 |
| Pass the uncorrected physical dropout screen | 7 |

**Seven is a screening count, not seven high-redshift galaxies.** No redshift
likelihood, astrophysical identity, purity, volume or population abundance is
estimated. The morphology classifier was not used to make this selection.

The three matched angular aperture radii are 0.1258253863, 0.1887380795 and
0.3145634658 arcsec, derived from the actual F444W WCS scale. The common annulus
is 0.3774761589–0.6291269315 arcsec. The audit uses the middle aperture and
requires calibrated finite Jy fluxes, positive errors, complete measurement
statuses and >=90% coverage, F444W SNR>=5, F090W SNR<=2, and
`(max(F090W,0)+2 sigma_F090W)/F444W < 0.05`. A non-detection limit requires actual
covered measurements; off-array bands retain null fluxes.

The **joint valid pixel-centre area is 0.962808 arcmin²**, or 20.92996% of the
valid F444W grid. Separate covered areas are 1.068165 arcmin² in F090W and
0.979276 arcmin² in F200W. Separate-band overlap fractions cannot replace the
intersection. These areas integrate actual spherical WCS pixel polygons, then
test reference centres against native comparison SCI/ERR/WHT masks. They do
not include an aperture-edge margin, PSF completeness or depth weighting, and
are not an effective survey volume. Pixel-centre membership is discretized.

The flux errors are diagonal ERR-plus-background estimates. The same geometric
aperture samples different filter PSFs. Empirical correlated-background/noise
and PSF aperture/annulus corrections therefore remain required before precision
colour interpretation. An empty-aperture correction is population/location and
operator dependent; it is not automatically an appropriate bright-source
Poisson-noise multiplier. All seven retained sources still need repeat/deep
imaging and contaminant controls.

## Reproduce

Provision the hash-pinned products using the acquisition workflow, then run:

```bash
python -m discovery.image_photometry_rerun \
  data/original_round2/images_manifest.json \
  --output-dir /tmp/original-image-rerun
python -m discovery.audit_candidates \
  --candidates /tmp/original-image-rerun/exploratory_proposals.json \
  --shortlist /tmp/original-image-rerun/dropout_screen_survivors.json \
  --output /tmp/original-image-rerun/standalone_audit.json \
  --report /tmp/original-image-rerun/standalone_audit.md
```

The new CLI invokes the existing Universe Table, WCS anchor selection, source
detector, calibrated aperture and physical audit functions. It does not need a
database registration, server, key or synthetic fallback. Each manifest row
declares `kind: science_image`, target, filter, path and SHA256. Missing inputs,
digests or required bands produce an explicit blocked result with null counts.
The detector threshold is 3 sigma and nine connected pixels; this is not an
assertion that each detected source has a 3-sigma integrated significance.
`--max-sources` can explicitly bound a brightest-segment-flux subset; the saved
run measured every detection.

Compact CSV measurements and their status/radius metadata preserve sufficient
information to rerun the physical audit without provisioning the images:

```python
from pathlib import Path
from discovery.image_photometry_rerun import load_selection_measurements
from discovery.audit_candidates import audit_candidate, summarize
p = Path("research_output/original_image_rerun")
rows = load_selection_measurements(p / "selection_measurements.csv", p / "selection_metadata.json")
print(summarize([audit_candidate(row) for row in rows]))
```

The compact catalog uses full round-trippable float representations and preserves
null versus measured zero. Full nine-aperture proposals and detector visualizations
are regenerated by the CLI. Unit tests exercise disjoint individual-band coverage,
invalid error masking, actual WCS area, manifest/hash rejection, explicit missing
data, the complete detector-photometry-audit chain and compact-catalog replay.
Those tests are synthetic controls, distinct from the saved real-image result.
